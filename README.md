# Stage & Stay Landing Page

English landing page for Stage & Stay, a Sydney property styling service.

The site uses a premium editorial visual direction inspired by Royce Property Styling: warm ivory backgrounds, deep garden green, muted terracotta accents, serif display typography, and real styled-property imagery.

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm run check
pnpm run build
```

The production client output is generated in `dist/public`.

## Included sections

The landing page includes the hero message, service value proposition, portfolio imagery, styling scope, three-step process, agent collaboration model, transparent contract conditions, FAQ accordion, and enquiry form success state.

## Important service wording

The page presents the service as conditional free styling: if the property sells and the agreed referral fee is paid by the agent, no styling fee is payable under the signed agreement. A fee may apply if the client withdraws from the sale, subject to the agreement. The signed Home Styling Service Agreement and applicable local laws govern the service.
